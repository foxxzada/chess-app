Stockfish.js browser engine notices
===================================

This application distributes the Stockfish 19.0.1 lite, single-threaded
WebAssembly engine from the `stockfish` npm package. It consists of
`stockfish-19-lite-single.js` and `stockfish-19-lite-single.wasm`.

Stockfish.js was created by Nathan Rugg and incorporates the Stockfish chess
engine, whose contributors are credited in `AUTHORS`. Stockfish.js source:
https://github.com/nmrugg/stockfish.js/tree/v19.0.1
Stockfish source: https://github.com/official-stockfish/Stockfish
Package: https://www.npmjs.com/package/stockfish/v/19.0.1

license text is in `Copying.txt`. The JavaScript and WebAssembly files are
prebuilt engine binaries; corresponding source and build information are
available from the Stockfish.js source repository above.
